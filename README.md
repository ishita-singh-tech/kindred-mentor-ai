# Mentor Match Pro

Create a complete working web application for an Intelligent Student Mentorship Allocation System for my B.Tech CSE AI PBL project.

Student Registration → Student Profile → Skills/Interests → Mentor Database → Matching Algorithm → Mentor Allocation → Dashboard → Feedback
